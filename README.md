# Lüga — Inteligencia Inmobiliaria · CABA

> Plataforma web para explorar Buenos Aires cuadra por cuadra: valor histórico del m², alertas de precio, calidad de vida por barrio y mapa minimalista sin ruido visual.

---

## 🚀 Solución de Negocio

Lüga centraliza y transparenta el mercado inmobiliario de la Ciudad Autónoma de Buenos Aires, cruzando la oferta de propiedades con datos urbanos reales:

- **Tasación y Métricas:** Estimación del valor histórico y actual del m² manzana por manzana.
- **Calidad de Vida:** Cruce con cercanía a estaciones de subte/tren, densidad de espacios verdes y mapas de contaminación sonora.
- **Alertas en Tiempo Real:** Notificaciones de oportunidades y bajas de precio por debajo de la media en los 48 barrios porteños.
- **Directorio y Transparencia:** Directorio de corredores matriculados e inmobiliarias verificadas.

---

## 🛠️ Stack Tecnológico

- **Next.js 15 (App Router) + React 19**
- **GSAP + ScrollTrigger + InertiaPlugin** — animaciones e interacciones de física
- **Lenis** — smooth scrolling inercial
- **Vanilla CSS** — sistema de diseño modular con variables CSS nativas

---

## ⚙️ Instalación y Uso

```bash
# Clonar el repositorio
git clone https://github.com/cruz-jenifer/luga-caba.git
cd luga-caba

# Instalar dependencias
npm install

# Servidor de desarrollo
npm run dev

# Build de producción
npm run build
```
